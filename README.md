# A Website About Me

## What is this?
This is my personal website. I made it because I wanted a place to show who I am and what I'm working on. It's a simple site where you can learn about me and see my projects.

## Why I made it
I'm Alex, I'm 15, and I love programming. I wanted to build something that's actually mine on the internet. I've been learning Python and Streamlit, so I thought this would be a good project to practice.

## What it does
- Shows a short intro about me
- Lists some of my projects
- Has links to my GitHub and Instagram
- Has a photo section
